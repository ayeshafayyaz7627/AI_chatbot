# AI_chatbot
It is a simple AI chatbot made using Python. The chatbot can answer some basic questions and have a simple conversation with the user.
## Features

- Greets the user
- Asks for the user's name
- Answers simple questions
- Gives responses about Python, AI, Machine Learning, and Programming
- Ends the chat when the user types `bye` or `exit`

## Technologies Used

- Python 3

## How to Run

1. Download or clone this project.
2. Open the project folder.
3. Run the file:

```bash
python lab.py
```

## Sample Questions

You can ask questions like:

- Hello
- Hi
- How are you?
- What is Python?
- What is AI?
- What is Machine Learning?
- What is Programming?
- Thank you

Type `bye` or `exit` to close the chatbot.
